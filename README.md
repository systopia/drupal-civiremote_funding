# CiviRemote Funding

This Drupal module provides the frontend part for applicants for the CiviCRM
extension [Funding Program Manager](https://www.github.com/systopia/funding).

See
[here](https://github.com/systopia/funding/blob/main/docs/administration/installation.md)
for installation instructions.

## Translation

Translations are managed in the `translations` directory. To extract the
translatable strings the Drupal module
[Translation template extractor (potx)](https://www.drupal.org/project/potx)
is used. With that module the translation template `civiremote_funding.pot`
can be generated at path `/admin/config/regional/translate/extract`.
